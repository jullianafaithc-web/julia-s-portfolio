HeatBeat / ThermoHead

A custom wearable headband-style device designed to monitor temperature, display readings on an OLED screen, and send Bluetooth fever alerts to a connected phone.

Tech: Seeed XIAO ESP32-S3 Sense, MLX90614, MAX30102, 0.96-inch OLED, Bluetooth, TP4056 charging module, 3.7 V Li-Po battery, MT3608 boost converter. Role: Documentation, feature planning, and ideation.

Three-Storey ICCT Campus LAN Design

A proposed network infrastructure for a three-storey building, including computers, switches, routers, wireless access points, structured cabling, and a ground-floor server room.

Tech: LAN, extended-star topology, CAT6 Ethernet, Dell all-in-one computers, D-Link switches, TP-Link routers, IP addressing, network planning. Role: Network design and equipment selection.

EdiDeliver Delivery Management System

A delivery management system designed to streamline delivery operations, order tracking, and coordination between customers, delivery riders, and administrators.

Tech: Web/mobile application development, database management, user authentication, order management, delivery status tracking, and location-based services. Role: System documentation, requirements analysis, feature planning, and system workflow documentation.
